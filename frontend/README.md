# Kampüs Etkinlikleri Yönetim Sistemi

Bu proje, Süleyman Demirel Üniversitesi Bilgisayar Mühendisliği Web Geliştirme dersi vize projesi olarak geliştirilmiştir.

## 🚀 Canlı Demo (Vercel)
Projenin canlı sürümüne aşağıdaki bağlantıdan erişebilirsiniz:
https://ebrareminebilen-frontend.vercel.app

## 🛠️ Kullanılan Teknolojiler
- React (TypeScript)
- React Router DOM v6
- Context API (EventsContext)
- CSS3 (Responsive Design)

## 📌 Özellikler
- 10 Farklı Sayfa Yönlendirmesi (Routing)
- Etkinlik Arama ve Kategoriye Göre Filtreleme
- Admin Paneli üzerinden Etkinlik Ekleme, Düzenleme ve Silme (CRUD)
- Form Doğrulamaları ve Hata Gösterimleri
- Mobil Uyumlu (Responsive) Arayüz
